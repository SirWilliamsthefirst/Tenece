Getting Started

Initializing a Repository

Use git init inside a project folder to start tracking it with Git. This creates a hidden .git directory that stores all version history.

Cloning a Repository

Use git clone <url> to copy an existing repository from a remote source, such as GitHub, to your local machine.

Branching

Branches let you work on features or fixes without affecting the main codebase. Create one with git branch <name> and switch to it with git checkout <name>, or do both at once using git checkout -b <name>.

Committing Changes

Stage changes with git add <file> (or git add . for everything), then save a snapshot with git commit -m "message". Good commit messages are short, imperative, and describe what changed.

Working with Remotes

Connect a local repository to GitHub with git remote add origin <url>, then push your commits using git push -u origin main. Pull new changes from others with git pull.

Command Reference Table

Common Git Commands
Command Purpose
git status Shows the current state of the working directory and staging area
git log Displays commit history
git diff Shows unstaged changes between the working directory and the last commit
git merge <branch> Merges the specified branch into the current branch
