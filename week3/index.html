Getting Started

Initializing a Repository

Use git init inside a project folder to start tracking it with Git. This creates a hidden .git directory that stores all version history.

  • git init — start tracking the current folder with Git
  • git init <folder-name> — create a new folder and initialize it as a repository

Cloning a Repository

Use git clone <url> to copy an existing repository from a remote source, such as GitHub, to your local machine.

  • git clone <url> — copy a remote repository to your machine
  • git clone <url> <folder-name> — clone into a custom folder name
  • git clone --depth 1 <url> — clone only the most recent commit (shallow clone)

Branching

Branches let you work on features or fixes without affecting the main codebase.

  • git branch — list all local branches
  • git branch <name> — create a new branch
  • git checkout <name> — switch to an existing branch
  • git checkout -b <name> — create and switch to a new branch in one step
  • git branch -d <name> — delete a branch that's already merged
  • git branch -D <name> — force-delete a branch, merged or not

Committing Changes

Stage and save snapshots of your work as you go. Good commit messages are short, imperative, and describe what changed.

  • git add <file> — stage a specific file
  • git add . — stage all changed files
  • git commit -m "message" — save a snapshot with a message
  • git commit -am "message" — stage all tracked files and commit in one step
  • git commit --amend — edit the most recent commit
  • git reset <file> — unstage a file without losing changes

Working with Remotes

Connect and sync your local repository with a remote source such as GitHub.

  • git remote add origin <url> — link a local repository to a remote one
  • git remote -v — view the remotes currently configured
  • git push -u origin main — push commits and set the upstream branch
  • git push — push commits after the upstream is already set
  • git pull — fetch and merge changes from the remote
  • git fetch — download changes from the remote without merging

Command Reference Table

Common Git Commands
Command Purpose
git status Shows the current state of the working directory and staging area
git log Displays commit history
git diff Shows unstaged changes between the working directory and the last commit
git merge <branch> Merges the specified branch into the current branch
git stash Temporarily shelves uncommitted changes so you can switch context
git stash pop Reapplies the most recently stashed changes
git rm <file> Removes a file from the working directory and stages the removal
git revert <commit> Creates a new commit that undoes the changes from a previous commit
git rebase <branch> Reapplies commits from the current branch on top of another branch
